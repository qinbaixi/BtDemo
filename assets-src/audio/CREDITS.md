# 音效素材来源

这个目录放替换程序化配方的真实音效：`assets-src/audio/<声音名>/` 下放一个或几个 wav（多个就是多个变体，播放时随机挑一个），然后在 `web/` 下运行 `npm run sfx:bake` 重新烘焙图集。声音名见 `web/src/audio/recipes.ts`，可以用通配名（比如 `hit.blade.*.heavy` 覆盖所有刀刃重击）。

每加一个素材，在下面记一行：声音名、文件、来源、作者、授权。只用可以商用的授权（CC0、CC-BY 并署名、自己录的、买断的）。
